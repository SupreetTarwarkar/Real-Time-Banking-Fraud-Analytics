# Security and responsible use

All project data is synthetic. Never commit Microsoft Fabric Eventstream connection strings, SAS keys, API secrets, `.env` files, local checkpoints or ground-truth validation CSVs. The approved simulator requests the connection string locally.

This is an educational portfolio project. A risk alert is not proof of fraud; potential exposure is not realized loss. No production payment blocking or regulatory certification is claimed.
